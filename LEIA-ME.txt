MICROSCÓPIO USB - PROJETO CORRIGIDO

O erro anterior era:
lib/screens/tela_principal.dart: No such file or directory

O arquivo agora está incluído em:
lib/screens/tela_principal.dart

Também foi adicionada a estrutura Android necessária para um projeto Flutter:
android/

Dependência:
flutter_ffi_uvc: ^0.12.0

Requisitos importantes:
- Flutter/Dart compatível com Dart >= 3.8.1
- Android minSdk 24

COMO COMPILAR

1. Abra a pasta microscopio_usb_corrigido como projeto Flutter.
2. Execute:
   flutter clean
   flutter pub get
   flutter build apk --release

O APK deverá aparecer em:
build/app/outputs/flutter-apk/app-release.apk

Se quiser APKs separados por arquitetura:
flutter build apk --release --split-per-abi

Observação:
O projeto foi preparado com a estrutura Android e os arquivos Dart. A compilação final ainda precisa ser executada em um ambiente que tenha Flutter + Android SDK/Gradle instalados e, para testar o microscópio, em um aparelho Android com suporte a USB OTG.
